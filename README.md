## 🛠️ 硬件与系统架构

- **主控芯片**：ESP32-S3 Dual-Core Xtensa LX7 @ 240MHz
- **屏幕配置**：1.14 英寸 135×240 竖屏 TFT LCD (ST7789v2)
- **存储方案**：8MB Flash (`app0: 2.5MB` 固件区 ＋ `littlefs: 5.4MB` 素材文件系统区)
- **图形管线**：片内超高速内部 SRAM 双缓冲 Canvas (`canvas.setPsram(false)`)，60fps 零撕裂渲染
- **网络模式**：`WIFI_AP_STA` 双模常驻开启，免密热点 `QQPet-StickS3`（IP: `192.168.4.1`），手机随时直连管理

## 🚀 快速开始与固件烧录

### 1. 环境准备
- 安装 [PlatformIO IDE](https://platformio.org/)（推荐 VSCode 插件）。
- 将 M5Stack StickS3 通过 USB-C 数据线连接至电脑。

### 2. 固件编译与双分区烧录

由于本项目采用了 8MB Flash 大容量 LittleFS 资源存储架构，首次烧录需依次执行以下两条命令：

#### 第一步：烧录核心程序固件
```powershell
pio run --target upload
```

#### 第二步：烧录 5.4MB 大容量素材文件系统到 8MB Flash
```powershell
pio run --target uploadfs
```

## 📂 项目结构说明

```
QQpet_StickS3/
├── data/                    -> LittleFS 5.4MB 大容量资源目录
│   └── assets/
│       ├── GG/              -> 男企鹅全套动作 (Egg / Kid / Adult)
│       ├── MM/              -> 女企鹅全套动作 (Egg / Kid / Adult)
│       ├── bg/              -> 16 款 135x240 原版裁切优化背景壁纸
│       └── icons/           -> 6 大官方菜单原版图标
├── src/
│   ├── asset_manager.h/cpp  -> LittleFS 高性能按需流式加载引擎与 RAM 缓存
│   ├── display_engine.h/cpp -> 135x240 竖屏 UI 渲染器与半轮盘物理旋转菜单
│   ├── pet_core.h/cpp       -> 宠物核心数值、疾病恶化树、打工与商城经济系统
│   ├── game_data.h/cpp      -> 100 级升级经验表、101 条 SmallTalk 语录、商城价格表
│   ├── web_server_portal.cpp-> 网页控制台端与 REST API
│   ├── network_manager.cpp  -> WIFI_AP_STA 双模 Wi-Fi 网络管理器
│   ├── imu_sensor.cpp       -> 6 轴 IMU 重力感应与防重入晃动检测
│   └── main.cpp             -> 系统主入口与状态机调度
├── tools/
│   ├── extract_all_to_littlefs.py -> 基于 Playwright + Ruffle 的 SWF 序列帧无损提取与调色板量化工具
│   └── generate_game_data_quotes.py -> 101 条官方 SmallTalk 语录自动生成脚本
├── partitions_8mb.csv       -> 8MB Flash 自定义分区表 (app0: 2.5MB, littlefs: 5.4MB)
└── platformio.ini           -> PlatformIO 工程编译与烧录配置
```
